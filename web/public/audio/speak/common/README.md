# 常用口語 6 篇｜真人錄音放置處

請把 MP3 檔放到**這個資料夾**（與本 README 同層）：

```
web/public/audio/speak/common/
```

## 檔名對照（請完全一致）

| 篇章 | 建議檔名 |
|------|----------|
| 1 新的一天 | `common-01-new-day.mp3` |
| 2 目標設定 | `common-02-goal-setting.mp3` |
| 3 料理步驟 | `common-03-cooking.mp3` |
| 4 海外旅遊與探索 | `common-04-travel.mp3` |
| 5 跨部門新產品發佈 | `common-05-product-launch.mp3` |
| 6 老屋翻新與智慧家居 | `common-06-renovation.mp3` |

## 規格建議

- 格式：`.mp3`
- 長度：約 40–80 秒／篇
- 放好後重新整理網站即可播放；尚未放置時仍可用單句喇叭（TTS）預練

網站上的路徑會是：`/audio/speak/common/<檔名>`
